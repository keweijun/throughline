## Language

Write project documentation, agent instructions, comments, and repository-owned examples in English. Use English by default in the UI and generated teaching content; learners may explicitly request another teaching language. Preserve the original language of imported sources and existing learning records.

Write commit messages, pull request titles and descriptions, issue titles and bodies, and repository discussion comments in English. Keep identifiers, links, evidence, and historical outcomes intact when translating existing records.

## Agent skills

### Issue tracker

Use this repository's GitHub Issues when creating, reading, or updating tasks. Follow `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default role labels when triaging tasks; see `docs/agents/triage-labels.md` for their meanings.

### Domain docs

This project uses a single-domain layout. Before exploring or changing it, follow `docs/agents/domain.md` to read the glossary and relevant ADRs.

### Learner workflow

For requests to build a course from documents, resume guided study, or open the learning interface, read `.agents/skills/guided-learning/SKILL.md`. The skill links course operations and app startup; it does not replace the installed Python app or the learner's course workspace.
