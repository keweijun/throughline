量子力学（上）习题一

波函数与叠加
1. 粒子在 $0 \le x \le L$ 内的波函数为 $\psi(x) = A\,x(L-x)$，其余处 $\psi = 0$。(a) 求 $A$。(b) 不做积分求 $\langle x\rangle$，并说明理由。(c) 在 $0 \le x \le L/4$ 内找到粒子的概率是多少？
2. 对第 1 题的态，求 $\langle p\rangle$ 和 $\langle p^2\rangle$。
3. 到达探测器的两条路径的概率幅分别为 $a = \tfrac{1}{\sqrt2}$ 和 $b = \tfrac{1}{\sqrt2}e^{i\phi}$（相差一个公共因子）。(a) 求相对概率 $P(\phi)$。(b) $\phi$ 取何值时探测器没有计数？(c) 在路径 2 上放一个探测器，记录每个经过的粒子。此时 $P(\phi)$ 是多少？
4. 动能为 $50\ \text{eV}$ 的电子通过间距 $d = 1.0\ \mu\text{m}$ 的双缝。估算 $L = 1.0\ \text{m}$ 处屏上的条纹间距。
5. 证明：把 $\psi_1 + \psi_2$ 整体乘以 $e^{i\gamma}$ 不改变任何概率，但只把 $\psi_2$ 乘以 $e^{i\gamma}$ 会改变概率。
6. 作用在试探函数上验证 $[\hat x,\hat p] = i\hbar$，并由此求 $[\hat x^2,\hat p]$。
7. 无限深方势阱中的态为 $\psi = \tfrac{1}{\sqrt3}\varphi_1 + \sqrt{\tfrac23}\,\varphi_2$。(a) 测量能量可能得到哪些值，概率各是多少？(b) 求 $\langle H\rangle$。(c) 这个态是定态吗？
8. 验证例 3.1 的高斯波包满足 $\sigma_x\sigma_p = \hbar/2$。
9. 电子被限制在宽 $L = 0.5\ \text{nm}$ 的势阱中。求 $2 \to 1$ 跃迁放出的光子的波长。
