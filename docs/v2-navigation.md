# Navigation and local rendering (#11)

Navigation reads the canonical curriculum and position. Preview opens an auxiliary view and never changes the teaching target. Mainline controls are locked to the current formal position; progression belongs to the practice flow. Existing recent V1 interactions are available under collapsed history; goal, next step and original progress remain visible without rewriting them.

A concept can supply `overview: {core_problem, steps, prior, next, target_ability}`. Otherwise the card is explicitly a route summary, not a teacher-authored overview. The first mainline reply for each concept is prompted to open with a substantive, topic-specific unit overview and then teach immediately in the same generation. It requires no additional model call or pre-written lecture. Subsequent replies use a short continuity reminder. This prompt contract does not certify model adherence; actual teacher replay must inspect the opening. There is no new formal unit grouping beyond the existing concept/section route.

Source buttons use registered source ID, content revision and unit ID. Exact snapshot bytes are SHA-256 checked, source paths are never accepted from the browser, and PDF links preserve the page fragment. Markdown shows the exact extracted line; missing locations and pending verification remain visible. PDF embedding depends on browser PDF support, with a separate open-original link available. Sources and branch views retain their nodes and scroll positions when switched.

Markdown is parsed by locally bundled Marked, sanitized into a DOM fragment by DOMPurify, with local KaTeX rendering (`trust:false`, bounded expansion). Remote images and active HTML are excluded. Standard Markdown tables/headings and `$...$`, `$$...$$`, `\(...\)`, `\[...\]` formulas render offline; unclosed streaming formulas remain readable text until complete. Unchanged rendered blocks stay alive to avoid disturbing selections. No runtime CDN dependency. `web_static/vendor/manifest.json` records npm tarball versions/integrity and per-file SHA-256; licenses accompany each package. References consulted: https://marked.js.org/ , https://github.com/cure53/DOMPurify , https://github.com/KaTeX/KaTeX/blob/main/docs/options.md .

Validation: `python -m unittest tests.test_web_navigation -v` covers public read-only preview, immutable Markdown/PDF source revisions, invalid source locators/path attacks, tamper detection and first-lecture overview prompt. `node tests/navigation_browser.cjs` (Playwright installed; `TEST_PYTHON` points at project Python) starts a disposable course/server and checks current-target isolation, Markdown/LaTeX/table rendering, unsafe HTML rejection, source viewing, refresh scroll preservation and narrow drawers. This test uses a fake model only. Shared suite and real-model acceptance are reported separately.
