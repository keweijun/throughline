# V2：保持学习连续性的独立学习界面

状态：设计、交互方向及验证边界已获用户确认；实施任务拆分待确认。2026-10-19。

## Problem Statement

完整讲解通常等待两三分钟；学习者难以判断当前位置及当前知识在整体路径中的作用。旁支问题需要及时解答，又不能淹没教学主线。现有记录流程重复生成完整讲解，增加等待。

## Solution

优先构建个人使用的独立学习界面，沿用现有课程工作区。单次生成讲解、流式展示并由程序保存；课程导航和单元导览保持位置感；旁支、来源和练习围绕主线展开。后台按小节备课，以实际收益决定后续扩展。

## User Stories

1. 作为学习者，我希望看到整课目录和当前目标，以便知道自己在哪里。
2. 作为学习者，我希望大单元开始自动展示核心问题、步骤、前后联系和目标能力，以便先理解整体。
3. 作为学习者，我希望点击知识点只预览，以便查看其他内容时不改变教学位置。
4. 作为学习者，我希望边生成边阅读完整讲解，以便减少无内容的等待。
5. 作为学习者，我希望新段落不强制滚动阅读位置，以便按自己的速度阅读。
6. 作为学习者，我希望针对一句话或公式提问，以便无需重新描述上下文。
7. 作为学习者，我希望普通旁支与主线并行，以便小问题不打断课程。
8. 作为学习者，我希望教师按路径决定旁支回答深度，以便兼顾眼前理解和后续安排。
9. 作为学习者，我希望补讲建议由我决定是否接受，以便掌控路线。
10. 作为学习者，我希望明确要求暂停后立即停止继续展开，以便有时间跟上。
11. 作为学习者，我希望补讲后回到主线恢复点，以便继续原目标。
12. 作为学习者，我希望点击来源打开对应原页，以便核对讲解。
13. 作为学习者，我希望小节结束集中练习并自由选择提示、步骤或答案，以便获得适当帮助。
14. 作为学习者，我希望练习可以暂缓且保留待办，以便自主控制推进。
15. 作为学习者，我希望看答案、听过和独立作答分别记录，以便进度可信。
16. 作为学习者，我希望备课就绪与学习状态分开显示，以便不混淆准备和掌握。
17. 作为学习者，我希望后台失败不阻塞学习，以便仍可由主教师完成必要准备。
18. 作为学习者，我希望跨次恢复目标、位置和未解问题，以便长期接续。
19. 作为学习者，我希望讲解自动保存且重试不产生重复记录，以便不承担记笔记的等待。
20. 作为学习者，我希望窄窗口仍能使用辅助视图，以便按当前窗口大小学习。

## Implementation Decisions

- 课程工作区仍持有唯一正式学习状态，复用已有课程操作入口及来源、路线、证据、教学恢复能力。界面不维护第二套课程进度。
- 优先独立学习 UI；左侧导航、中间教学、右侧按需辅助。右侧默认收起，旁支和原页切换时保留位置，窄屏改为抽屉。具体视觉样式未定。
- 教师只生成一次正式回复。宿主接收流式内容，并将完成事件中的权威正文关联到课程记录；不要求教师先写一份完整讲稿再复述。
- 暂停、断线及未完成回复需要显式状态。不得把部分内容当作已完成讲解，不把重复事件写成重复证据。恢复是否续流或重新发起由传输能力验证后决定。
- 普通旁支不推进主线；需要补先修时先建议，用户接受后暂停调整。明确暂停直接执行，当前讲解错误应停止并纠正。
- 单元导览后直接开始首节。下一小节由用户推进；没有强制练习通过门槛。已讲解、练习待完成和掌握证据保持独立。
- 整单元规划，小节粒度备课，默认仅提前一节、最多一个活跃备课任务。主线与即时提问优先；未就绪由主教师接管必要核对。
- 备课结果与来源和路线版本关联；无关或过期结果不得覆盖较新的路线与学习状态。后台离开会话后的生命周期尚未验证，不承诺退出后常驻。
- 模型接入优先沿用已实测通道；实际并发能力、取消语义、资源竞争和课程事务关联属于集成验证项，不由原型证明。

## Testing Decisions

已确认的验证边界：沿用课程操作入口检验正式状态，增加客户端到模型事件流的集成边界，并用少量浏览器场景验证可见交互。

- 课程行为：预览不移动主线，旁支恢复准确，跳过与看答案不升级掌握；新进程重开可恢复，旧结果和重试不覆盖新状态。参考现有课程、教学、证据、后台测试。
- 流式记录：真实事件经过适配器进入课程记录，确认展示与最终正文一致、仅保存一次；模拟重复、乱序、断线及暂停，不以模拟结果冒充真实服务能力。
- 浏览器行为：选句提问、旁支返回、来源原页、补讲暂停恢复、暂缓后推进，以及不强制跳滚动位置。
- 真实集成：至少验证一次模型完整输出与记录、一次暂停及后续恢复、一次主线与旁支并发。不能只用模型替身证明并发可用。
- 性能：记录前 200 字实质讲解时间、全文时间、保存时间，以及有无备课时即时答疑延迟。保持目标、长度与质量；报告样本分布和失败，不把此前三组收益承诺为 SLA。
- 教学回放：检查旁支深度、主线接续、练习提示和关键概念覆盖；程序通过与教学质量分别报告。

## Out of Scope

Obsidian 兼容、多用户账号、完整 Codex 桌面镜像、公开插件发布、移动端专用应用、整章预生成、自动新增付费 API 通道。原型不代表最终视觉设计，不直接作为生产代码交付。

## Further Notes

三组单次输出实验全文合计耗时降低约 37%，前 200 字平均约 90 秒降至 31 秒；样本量小且在隔离客户端中测得。备课实验收益不一致，因此先落实单次输出，再测并发和备课。

用户已接受交互原型方向，未取得逐场景操作日志，不能声称用户完成全部走查。原型保存与实施任务链接在发布阶段完成。该规格扩展 V1 专用 UI 的原有范围，不改变课程状态归属。
