# V2 实施任务拆分草稿

2026-10-19。规格及验证边界已确认；以下拆分待用户确认后发布。编号为草稿编号，不是 GitHub Issue 编号。

1. **真实授课、单次保存与中断恢复**。无前置。打开现有课程，在最小学习页发起真实讲解，流式显示并自动保存；刷新重开可恢复，取消及未完成回复有明确状态。验收：正式完成正文一致、重试不重复记录、部分输出不算完成、真实暂停恢复、首段和全文延迟有记录。复用课程入口，必要适配在此小步完成。
2. **课程导航、单元导览与来源查看**。依赖 1。读取正式路线，显示整课目录、当前目标和局部流程；首节展示单元导览，跨次给接续提醒；点击节点只预览，点击引用打开可核验原页。验收：不改变教学位置、无定位时明确标识、窄窗口可使用、不强制跳滚动位置。
3. **旁支答疑、补讲与返回主线**。依赖 1。选中一句话或公式提问，携带路径上下文；普通旁支与主线并行，补先修需接受建议，明确暂停直接执行，返回恢复原位置。验收：真实并发与资源竞争检查、迟到事件不重启已暂停内容、旁支不推进主线；回放简答、深入、补讲三种场景。辅助视图可独立实现，不要求导航完成。
4. **小节练习、提示与自主推进**。依赖 1。题目先展示，允许逐步提示或直接解答，作答进入现有证据机制；稍后做保留待办，由用户推进下一节。验收：看答案和暂缓不记掌握、重开保留待办、提示记录与独立作答可区分、不强制通过才能继续。
5. **下一小节备课与前台优先**。依赖 3、4。以当前路线与小节推进为依据，至多一个活跃任务提前准备下一节；状态可见且与掌握分离，未就绪由教师接管必要准备。验收：实际备课调用、来源/路线变化失效、失败降级、旧任务不改新状态；对照有无备课的即时答疑延迟，不承诺未验证的退出后常驻。
6. **完整学习流程与连续性验收**。依赖 2、3、4、5。把现有量子课程接入完整界面，执行导览—讲解—插问—来源—练习—继续—跨次恢复；修复接缝问题并分别报告程序、真实集成、教学与性能结果。验收：保留讲解长度与概念覆盖，报告分布与失败样本；核验窄屏辅助区及多视图阅读位置，不以静态原型代替真实操作。

首个可实施任务是 1；其后 2、3、4 没有彼此的硬依赖。前序每项自行完成测试及可演示验收，第 6 项不承接前序遗漏的基本验证。任务发布时建立真实依赖关系；此草稿不授权自动开始生产实现。
